Publish directly
How to make the token (once)
  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it "Motoreka accounts". Repository access: Only select repositories → .
  3. Permissions → Repository permissions → Contents: Read and write. Generate, copy, paste above.
Or upload by hand
  1. Open the upload page: . It must be this repository and folder; a users.json anywhere else is not read.
  2. Drop users.json there → Commit changes (to main).
  3. The site updates in about a minute.
